# Token Saver Meta — Rewrite Strategy

> **Status:** AUTHORITATIVE — supersedes all previous bundling assumptions.
> **Created:** 2026-06-18
> **Based on:** GitHub star audit (14 tools), 4 codebase deep studies (ContextSlimAI, TSCG, codex-agent-mem, Loom), Oracle architecture evaluation, 63-source insight corpus

---

## Executive Summary

Of the 14 tools in architecture v2, **8 are safe to bundle**, **2 are blocked by license**, and **6 are micro-tools (<1K stars) that require rewriting or vendoring**. The rewrite strategy is: SKILL.md tools → vendor as text (merge into AGENTS.md); code tools → study mechanism → rewrite in Python with better architecture.

## 1. Base Layer SKILL.md Tools — Vendor As Text

These 4 tools are ZERO-DEPENDENCY text files. Rewriting means extracting their rules and merging them into our single tiered AGENTS.md block.

### Merged Rules Inventory

| Source | Rules | What They Do |
|--------|-------|-------------|
| **caveman** | Terse output style | Drop filler, explanations, pleasantries. Keep accuracy. ~75% output reduction. |
| **ponytail** | YAGNI code ladder | stdlib→native→dep→one-liner→minimal. ~54% LOC, ~22% tokens. 100% safe. |
| **LG-token-saver** | 8 operational rules (R1-R8) | SubAgent for exploration, Grep before Read, Batch parallel, Never repeat, Filter Bash output, Terse replies ≤200w, Compact early, Limit subagent output. |
| **kevin-copilot** | CI-gated terseness modes | lite/full/ultra modes, must beat generic "be terse" baseline by ≥5pp. GitHub Copilot specific → generalize to all agents. |

### Merged AGENTS.md Structure

```markdown
<!-- TOKEN_SAVER_START -->
## Token Saving Protocol (auto-generated by Token Saver Meta)
### Rule 1: Terse output (caveman) → Speak directly. Lead with answer.
### Rule 2: YAGNI code (ponytail) → stdlib first, minimal code.
### Rule 3-10: Operational (LG-token-saver) → parallel, grep-first, batch, no-repeat, filter, compact, limit.
### Rule 11-14: Structure (kevin-copilot) → lite/full/ultra modes.
<!-- TOKEN_SAVER_END -->
```

### What to Drop

- **kevin-copilot's 40+ agent reviewer files** (irrelevant to token saving — they're for code review)
- **kevin-copilot's Copilot-specific config format** (generalize to all agents)
- **LG-token-saver's modes (lite/full/ultra)** → simplify: "Use all rules, agent auto-adjusts"
- **LG-token-saver's `/cost` command** (platform-specific)
- **kevin-copilot's GitHub Copilot `copilot-instructions.md`** (not our format)
- **All non-SKILL.md files** from kevin-copilot (~60 files / 200+KB of reviewer definitions)

## 2. ContextSlimAI — Python Rewrite

### What We're Replacing

39 CLI subcommands (6,500 LOC TypeScript) → Python with `rich` + `click`.

### What to Keep, Improve, Drop

**KEEP** (core value, port directly):
- Command catalog: `cat`, `grep`, `ls`, `tree`, `map`, `head`, `brief`, `outline`, `imports`, `types`, `deps`, `todo`, `diff`, `changes`, `errors`, `logs`, `config`, `summary`, `compare`
- Stack auto-detection from 30+ file signals
- Output compression strategies: truncate-middle, strip-blanks, cap-matches, strip-timestamps, hide-sensitive-env
- Cross-platform abstractions (`isWindows()` → `platform.system()`)
- Generator pattern: ignore files + AI rules

**IMPROVE** (better in Python):
- Replace `commander + chalk + ora + @inquirer` → single `rich` library (covers CLI, colors, spinners, prompts)
- DB layer: replace external CLI (`sqlite3`, `mysql`, `psql`) → native Python drivers (`sqlite3` stdlib, `pymysql`, `psycopg2`)
- Add `pytest` test suite (original has `"test": "echo 'Error: no test specified'"` — literally no tests)
- Better token estimation: `tiktoken` for accuracy, fallback to chars/4
- Parallel execution: `asyncio` or `concurrent.futures` for multi-file operations
- Config: TOML instead of JSON

**DROP** (unnecessary complexity):
- Interactive `init` checkbox → CLI flags: `--ides cursor,claude`
- `scan` + `stats` → merge into single `audit` command
- `meter` subsystem (672 lines) → drop session store, keep `simulate` only
- `registry` command → Windows-only, niche
- `tail`, `run` → safety features, defer to optional plugin
- MongoDB support → too fragile
- `compare` (set-based) → already redundant with `diff`

## 3. TSCG — Python Rewrite

### What We're Replacing

8-transform deterministic compression pipeline (2,880 LOC TypeScript) → Python with official `mcp` SDK.

### The 8 Transforms (to Port Exactly)

1. **SDM** — 27 regex patterns strip filler from descriptions
2. **CAS** — U-shape reorder by usage frequency (high→edges, low→middle)
3. **CFO** — Causal ordering: READ → TRANSFORM → WRITE tools
4. **DRO** — Compact format: `tool_name(param* type: vals)` 
5. **TAS** — BPE-optimized delimiters
6. **CFL** — Prepend `[ANSWER:function_call]` (Claude-only)
7. **SAD** — Append `[ANCHOR:top-K]` (Claude-only)
8. **CCP** — Append `[CLOSURE:tool1(req1),tool2()]`

### Critical Guards to Port

- CFL/SAD auto-disable for non-Claude (GPT/Gemini echo tags back)
- CFO auto-disable at ≥30 tools
- Auto-profile: ≤20→conservative, ≤40→balanced, >40→conservative
- Thinking models excluded (o1, o3, R1)
- SAD for `auto` model defaults to ON

### Architecture

```
tscg-py/
├── pyproject.toml              # mcp (PyPI) + stdlib only
├── src/tscg/
│   ├── __init__.py             # Public API: compress(), compress_tools()
│   ├── core/
│   │   ├── transforms.py       # All 8 transforms
│   │   ├── compiler.py         # Pipeline orchestrator
│   │   ├── profiles.py         # Model profiles (14 families)
│   │   └── utils.py            # Token estimation
│   └── proxy/
│       ├── server.py           # MCP proxy (mcp SDK)
│       ├── downstream.py       # Spawn connect downstream servers
│       ├── router.py           # Tool→server map
│       ├── compressor.py       # MCP tool ↔ TSCG format
│       └── config.py           # ENV-based config
└── tests/
```

### What to Skip

- `@tscg/tool-optimizer` (LangChain/Vercel wrappers) — out of scope
- OpenClaw adaptive tuning — out of scope
- Browser bundle — irrelevant
- Benchmark harness — defer

### What to Enhance

- Add `anyOf`/`oneOf`/`allOf` schema support (currently lost)
- Add nested object param support (currently flattened)
- Add `tiktoken`-based accurate token counting
- Add SSE transport alongside stdio

## 4. codex-agent-mem + Loom — Unified T5 Python Rewrite

### Why Merge

Loom and codex-agent-mem are **complementary, not overlapping**:
- **Loom** → indexes source code structure (symbols, call graphs, function summaries)
- **codex-agent-mem** → indexes session artifacts (decisions, objectives, blockers, DoD items)

Together they provide complete T5 coverage. A single MCP server with 8-10 tools can serve both.

### What to Extract from Loom (6 mechanisms)

| Mechanism | Source File | Why Extract |
|-----------|-------------|-------------|
| **3-tier incremental indexing** | `incremental.py` (184 lines) | mtime → SHA → reparse. Drop tree-sitter, keep content_hash approach. |
| **Session delta tracking** | `delta.py` (145 lines) | `updated_at` only bumps on content change (SQL CASE guard) |
| **Summary staleness** | `store/nodes.py` | `summary_hash` snapshots `content_hash`. Diverge → stale. |
| **Annotation gap detection** | `node_visits.py` (120 lines) | Log visits → find top nodes without agent summaries |
| **get_work_plan()** | `analysis.py` | Combine gaps + structural analysis → prioritized tasks (~200 tokens) |
| **Auto-summaries** | `extractor.py` | Tree-sitter metadata → structural summaries. Replace tree-sitter with `ast` (stdlib) for Python. |

### What to Keep from codex-agent-mem

| Mechanism | Source File | Why Keep |
|-----------|-------------|----------|
| **Continuity pack builder** | `context_pack.py` (248 lines) | 3 budget tiers, auto-budget, Markdown format. Already solid. |
| **Hash caching (304-style)** | `mcp_stdio.py` lines 903-924 | `known_pack_hash` → `not_modified`. Zero-token re-retrieval. |
| **Operational state derivation** | `operational_state.py` (128 lines) | Dedup, resolution matching, guardrail generation. |
| **Bootstrap context** | `mcp_stdio.py` | Scope resolve + pack = full context in one call. |
| **SQL schema** | `schema.sql` (229 lines) | 13 well-indexed tables, FTS5. Keep and extend. |

### Unified T5 Architecture

```
token-saver-mem/
├── pyproject.toml              # mcp, sqlite3, tiktoken (optional)
├── src/token_saver_mem/
│   ├── __init__.py
│   ├── server.py               # MCP server (unified tools)
│   ├── store/
│   │   ├── db.py               # SQLite connection, schema
│   │   ├── schema.sql          # 13 tables + FTS5
│   │   └── repository/         # NodeRepo, EdgeRepo, ObsRepo, SessionRepo
│   ├── code_memory/            # ← Loom mechanisms
│   │   ├── indexer.py          # File walker + content_hash + parse (ast for Python)
│   │   ├── delta.py            # Session delta (timestamp + hash guards)
│   │   ├── staleness.py        # Summary vs content hash comparison
│   │   ├── gaps.py             # Annotation gap detection
│   │   ├── auto_summary.py     # ast metadata → structural summary
│   │   └── work_plan.py        # Prioritized annotation tasks
│   ├── session_memory/         # ← codex-agent-mem mechanisms
│   │   ├── extractor.py        # LLM-based extraction (IMPROVED: replace regex heuristics)
│   │   ├── state.py            # Operational state derivation
│   │   ├── continuity.py       # Continuity pack builder (3 budget tiers)
│   │   ├── caching.py          # Hash cache + ShortTTLCache
│   │   ├── bootstrap.py        # Scope resolve + pack = one-call bootstrap
│   │   └── closure.py          # Completion check, open work report
│   └── tools/
│       ├── code/               # search_symbols, get_context, store_understanding, get_delta
│       └── session/            # context_pack, bootstrap_context, open_work, completion_check
└── tests/
```

### Key Architectural Improvements

| Improvement | Rationale |
|------------|-----------|
| **Split db.py** | 4,273-line monolith → 5 modules (store + 4 repositories) |
| **LLM-based extraction** | Replace heuristic regex (`noop.py`) with tiny local model or structured agent prompting. ~200 lines vs 245 regex lines but far more reliable. |
| **ast for Python** | Replace tree-sitter 12 C extensions with `ast` (stdlib). Zero compile deps. Python-only in v1; other languages opt-in. |
| **8-10 tools** (down from 29+22=51) | Combined server exposes only essential tools. Tool schema: ~3K → ~1K tokens. |
| **Read-only by default** | Mutating tools behind `--write` flag. Safer default for T5. |
| **Remove inspector UI** | FastAPI + Jinja2 + uvicorn → optional. Core: stdio only. |
| **Proper async** | Use `mcp` SDK async instead of threading for daemon. |
| **Remove Codex dependency** | Generic MCP tool capture + file-watching. Decouple from `notify` hook. |

### Target MCP Tools (8-10)

| Tool | Source | Purpose |
|------|--------|---------|
| `search_symbols` | Loom | FTS5 search on indexed code symbols |
| `get_context` | Loom | Full context packet (summary, callers, callees, staleness) |
| `store_understanding` | Loom | Agent writes summary → cached for next session |
| `get_delta` | Loom | Changed functions since last session |
| `get_work_plan` | Loom | Prioritized annotation tasks |
| `context_pack` | codex-agent-mem | Compressed session continuity (with hash caching) |

## 5. GitNexus — License Blocker Resolution

### The Problem
GitNexus (`abhigyanpatwari/GitNexus`, 42K stars) is licensed under **PolyForm Noncommercial License 1.0.0**. This means:
- ✅ Free for personal, educational, research, government, charitable use
- ❌ **Cannot be bundled in any commercial distribution**
- ❌ **Cannot be part of token-saver-meta's default install if used commercially**

### Resolution Options

| Option | Description | Effort |
|--------|-------------|:------:|
| **A: Non-commercial only path** | Install GitNexus only when user confirms "non-commercial use". Warn during install. | Low |
| **B: Seek commercial license** | Contact author (Abhigyan Patwari) for a commercial bundling license. | Medium |
| **C: Replace with alternative** | Use CGC/codegraph (MIT, 51K stars) as primary T1 graph tool. GitNexus becomes optional. | Medium |
| **D: Fork under MIT if possible** | If the author is willing to relicense. | Low effort, uncertain outcome |

### Recommendation: **Option C (Replace) + Option A (Fallback)**

CGC/codegraph (`colbymchenry/codegraph`, 51K stars, MIT) provides the same SQLite+FTS5 graph query capability. It can serve as the PRIMARY T1 tool. GitNexus becomes an optional "non-commercial only" module.

**Architecture change**: Move GitNexus from Intelligence Layer (Core) to Optional Layer. Install only when user confirms non-commercial use.
